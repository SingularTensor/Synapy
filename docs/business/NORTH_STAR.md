## Core Outcome
- Outcome statement: `Maximize meaningful daily active users while preserving engagement quality.`
- Time horizon: `90 days`
- Why this matters now: `Synapy needs fast user loop density, behavior data, and engagement compounding.`

## Target User
- Primary segment: `Individual puzzle players and career-improvement users (consumer first).`
- Jobs-to-be-done: `Train cognitive skills`, `measure progress`, `prepare for role-relevant challenges`.
- Buying trigger: `Need a practical, low-friction daily training loop with measurable progression.`

## North-Star Metric
- Metric name: `DAU (Meaningful Gameplay DAU)`
- Formula: `Unique users per day who complete >= 1 puzzle session (excluding simple pageviews/logins).`
- Baseline: `TBD after telemetry verification window (target date: 2026-02-28).`
- 30-day target: `Set after baseline lock.`

## Guardrail Metrics
- D7 retention for new users: `>= 20%`
- DAU completing >= 3 sessions/day: `>= 30%`
- New users completing first session: `>= 60%`
- Qualified data pairs/day (cross-project): `Track as strategic secondary output`

## 90-Day Milestones
- Days 1-30: `Finalize event definitions, establish baseline, remove onboarding friction.`
- Days 31-60: `Improve repeat session behavior and progression loops.`
- Days 61-90: `Scale acquisition only if guardrails hold while DAU grows.`

## Non-Goals

- `Do not prioritize broad enterprise features before daily engagement quality is stable.`
